# Grocery Shopping List Manager

## Overview
The Grocery Shopping List Manager is a menu-driven Python application that allows users to create and manage a grocery list while tracking individual item prices.

Developed as part of CGS2060, this project demonstrates foundational Python programming concepts through an interactive command-line application.

## Features
- View grocery items and their prices
- Add and remove grocery items
- Insert items at a specific list position
- Remove the last item
- Search for items and view their prices
- Clear the entire grocery list
- Add multiple items using comma-separated input
- Calculate total, lowest, and highest item prices
- Validate user input and handle common errors

## Python Concepts Demonstrated
- Variables and data types
- Lists and list methods
- List indexing
- Functions and parameters
- While and for loops
- Conditional statements and match-case
- Comparison operators and Boolean logic
- String manipulation
- Exception handling
- Input validation
- Basic calculations

## How to Run
1. Download or clone this repository.
2. Open the project in a Python environment.
3. Run `grocery_list_manager.py`.
4. Follow the interactive menu to manage your grocery list.

## Technologies
- Python 3.10+
- Built-in Python libraries
